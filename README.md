# Student Records Management System

A simple full-stack Python web application built with Flask, SQLite, Bootstrap, and CRUD operations.

This project was created to practice full-stack development workflows including backend logic, database operations, form handling, validation, search, and debugging.

## Features

- Student dashboard
- Add student
- View students
- Edit student
- Delete student
- Search students
- Form validation
- SQLite database
- Bootstrap responsive UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
